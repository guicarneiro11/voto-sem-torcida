# Política de segurança

Encontrou uma vulnerabilidade? Não abra uma issue pública.
Envie para: guicarneiro.dev@gmail.com ou https://x.com/guizaokt (responderemos em até 72h).

Erros de conteúdo (posição de candidato errada, fonte quebrada) podem ser
reportados publicamente via issue, com o link da fonte correta.

## Garantias do projeto
- As respostas do eleitor são processadas só no navegador. Nada é enviado ou salvo.
- O site não usa cookies nem scripts de terceiros.
- Todo o conteúdo é público neste repositório, com fonte e página de cada posição.
- O deploy só acontece a partir da branch `main`, após a CI passar.
